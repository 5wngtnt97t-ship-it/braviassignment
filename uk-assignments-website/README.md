# Bravin Morara Academic Writing Website

A static HTML website with red color theme for Bravin Morara academic writing services.

## Files Created

- `index.html` - Main homepage
- `order.html` - Order form with price calculator
- `how-it-works.html` - 5-step process
- `prices.html` - Transparent pricing
- `services.html` - Service offerings
- `about.html` - About Bravin Morara
- `contact.html` - Contact page
- `resources.html` - Student writing guides
- `login.html` - Sign In / Sign Up page

## Features

### Animations & Effects
- AOS scroll animations (fade, zoom, slide effects)
- Floating WhatsApp button with pulse animation
- Hover animations on buttons and cards
- Launch animations on page load

### Order Form
- Dynamic price calculator based on:
  - Service type
  - Academic level (undergrad/master/phd pricing)
  - Deadline urgency
  - Word count
- Base price: $13.50 per 250 words (20% reduction applied)
- WhatsApp integration - calculated prices auto-send to Bravin Morara's WhatsApp

### Login System
- Sign In / Sign Up tabs
- Profile dashboard after login
- Full screen profile view with order button

### Navigation
- All pages linked from header navigation
- Quick links in footer to all pages
- Mobile responsive menu

### Social Media
- WhatsApp button (fixed floating + footer)
- Instagram link in footer

## How to Use

Open `index.html` in any web browser. All pages are fully interconnected.
